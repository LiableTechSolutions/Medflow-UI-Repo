# Footer

## Purpose
Footer provides a consistent closing region for public or application layouts.

## When to use
Use for product identity, legal links, or supporting navigation at the end of a layout.

## When NOT to use
Do not use as a substitute for primary navigation or to repeat every page action.

## Props

| Name | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| none | - | - | - | Current implementation is content-only. |

## Variants
No configurable variants are exposed.

## Sizes
Height follows content and footer tokens.

## Accessibility
Use a footer landmark and ensure any links have descriptive names.

## Usage
```tsx
<Footer />
```

## Best Practices
Keep content short and useful.

## Anti-patterns
Do not place critical actions only in the footer.

## Related Components
AuthLayout, AppLayout, Header.
